tradinganalysis

Multi-agent equity research for NIFTY 50 stocks, built from Claude Code parts: one MCP data server, twelve subagents and an /analyze skill. It follows the design of TauricResearch/TradingAgents (Apache-2.0), adapted for Indian markets and free data. It is for research and decision support and never places orders.

Universe: NIFTY 50 Horizon: 5 trading days Benchmark: ^NSEI Runtime: Claude Desktop · EbenezerOne Orders: disabled
One run of /analyze SYMBOL DATE

Agent pipeline

  1. parallel · sonnet4 analystsMarket, Fundamentals, News, Sentiment. Each writes a report.
  2. 1 round · sonnetBull vs BearDebate using the four reports as evidence.
  3. opus · JSONResearch Manager5-tier call: Buy, Overweight, Hold, Underweight, Sell.
  4. sonnet · JSONTraderBuy/Hold/Sell with entry, stop and target in INR.
  5. 1 round · sonnetRisk debateAggressive, Conservative and Neutral views.
  6. opus · JSONPortfolio ManagerFinal rating. Reads Kite holdings in live mode and lessons from past runs.

Claude Code subagents can't start other subagents, so the skill in the main session runs every step. Agents hand work to each other through files in runs/SYMBOL/DATE/, which also keeps an audit trail.

No look-ahead rule. Kite tools can't be limited to a past date, so they run only when as_of is today. Backtests use only the project's own MCP server. A quarter's results stay hidden until quarter-end + 45 days (60 for Q4/annual), the SEBI LODR Reg. 33 filing deadlines. That's conservative and can lag the actual announcement.
  • The Sentiment analyst reads news tone and price/volume behaviour. India has no free StockTwits or Reddit-style API.
  • Macro context comes from market prices: ^NSEI, ^NSEBANK, ^INDIAVIX, USDINR=X, Brent, US10Y. FRED (free key) is optional later.
  • v1 uses the current NIFTY 50 constituents. Backtests on that list carry survivorship bias, and reports will say so.

Limits to keep in mind

Risks

  • LLM output varies from run to run. On small backtest grids, results are mostly noise.
  • yfinance is unofficial, so fields and rate limits can change. Cache data locally and expect occasional breakage.
  • Kite sessions expire daily, so you log in once each trading day.
  • A full run makes 12+ subagent calls. It uses subscription limits, and backtests multiply that.
