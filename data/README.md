# data/

`nifty50.csv` is a pinned copy of NSE's NIFTY 50 constituent list
(`https://archives.nseindia.com/content/indices/ind_nifty50list.csv`), downloaded 2026-11-05.

NSE reviews the index twice a year. Re-download it after each rebalance and commit the new copy.
Backtests over past dates use this current list, so they carry survivorship bias.
